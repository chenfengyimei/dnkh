电脑开荒 v0.1.0 发布说明
========================

下载文件
--------
- 文件名：Dnkhw.exe
- 大小：58.96 MB（61,824,556 字节，自包含单文件，免安装）
- SHA256：5B3D250679F09C9556D2DDC5767CCCCC95DEF4F8D20EC8932DE3400CEC4A0279
- 校验方法：在文件所在目录打开命令行，执行
  certutil -hashfile Dnkhw.exe SHA256
  对比上面的一致即未损坏、未被篡改

系统要求
--------
- Windows 10（1709 及以上）或 Windows 11，64 位
- 无需安装 .NET 运行时
- 「APP 推荐」一键安装功能依赖系统自带的 winget（App Installer），Win10 早期版本可在微软商店免费安装，应用内有引导按钮

安装与运行
----------
1. 将 Dnkhw.exe 放到任意目录（建议放在非系统盘，如 D:\Tools）
2. 双击运行
3. 首次运行如弹出 SmartScreen 蓝色提示：点「更多信息」→「仍要运行」
   （个人作品未购买代码签名证书的正常现象，软件本身是干净的）
4. 更省事的做法：右键文件 → 属性 → 勾选「解除锁定」→ 确定，之后再无提示

权限说明
--------
- 默认以普通权限运行，开荒检查 / 壁纸 / 下载路径换盘 / APP 推荐 / 磁盘分析均可用
- 系统级启动项、关闭遥测等少数操作需要管理员：页面内点「以管理员身份重启」，确认 UAC 即可
- 不需要管理员的功能不会要求提权

纯净承诺
--------
- 无广告、无弹窗、无捆绑
- 不收集、不上传任何数据（仅联网访问 Bing 壁纸接口与 winget 官方源）
- 磁盘分析只读展示，绝不自动删除文件
- 所有系统修改（启动项禁用 / 优化项）均可在应用内一键恢复

功能一览
--------
- 开荒检查：一键体检（激活 / 安全防护 / 驱动 / 待重启 / 网络 / 磁盘），导出 Markdown 报告
- 壁纸开荒：Bing 每日壁纸一键设置，支持本地图片与 5 种填充模式
- 下载路径换盘：下载文件夹一键迁到 D 盘，浏览器自动跟随
- APP 推荐：25 款精选纯净软件，winget 静默安装
- 启动项管理：任务管理器同机制，完全可逆
- Windows 优化：9 项推广/广告功能一键关闭，随时恢复
- 磁盘分析：目录/大文件占用排行 + 可清理位置（只看不删）
