电脑开荒 v1.0.1 发布说明
========================

下载文件
--------
- 官网：www.cyhaoka.vip（软件下载、使用帮助与最新版本）
- 文件名：Dnkhw.exe
- 大小：67.00 MB（70,213,351 字节，自包含单文件，免安装）
- SHA256：94904A36CDF6167B06766844B094100A633968B57BD16F4363B5213ADA5A959C
- 本版亮点：**应用内在线更新**——关于页「检查更新」发现新版本后可直接「在线更新」：
  应用内下载 → SHA256 强校验 → 原地替换 → 确认重启，全程无需手动去官网下载替换。
  更新源按 GitHub Releases → Gitee Releases → 官网 version.json 多级回落，
  开源仓库建立后即接入（代码内仅改一处常量）；未提供哈希的源只引导官网，绝不替换未校验的文件。
- 校验方法：在文件所在目录打开命令行，执行
  certutil -hashfile Dnkhw.exe SHA256
  对比上面的一致即未损坏、未被篡改

升级方式
--------
- v1.0.0 用户：打开应用 → 左下角「关于」→「检查更新」→ 会提示发现 v1.0.1 并引导官网下载（v1.0.0 尚无在线更新能力，本版起之后的升级都可在应用内完成）
- v1.0.1 及以后用户：「检查更新」→「在线更新」→ 一键完成

系统要求
--------
- Windows 10（1709 及以上）或 Windows 11，64 位
- 无需安装 .NET 运行时
- 「电脑开荒网」内嵌页依赖系统 WebView2 运行时（Win10/11 一般随 Edge 自带）
- 「APP 推荐」一键安装依赖系统自带的 winget（App Installer）

安装与运行
----------
1. 将 Dnkhw.exe 放到任意目录（建议放在非系统盘，如 D:\Tools）
2. 双击运行
3. 首次运行如弹出 SmartScreen 蓝色提示：点「更多信息」→「仍要运行」
   （个人作品未购买代码签名证书的正常现象，软件本身是干净的）
4. 更省事的做法：右键文件 → 属性 → 勾选「解除锁定」→ 确定

权限说明
--------
- 默认以普通权限运行，绝大多数功能可用
- 系统级启动项、关闭遥测等少数操作需要管理员：页面内点「以管理员身份重启」
- 在线更新不需要管理员权限（下载目录与 exe 重命名均无需提权）

纯净承诺
--------
- 无广告、无弹窗、无捆绑
- 不收集、不上传任何数据（仅联网访问 Bing 壁纸接口、winget 官方源与官网）
- 检查更新只在你点击时联网；在线更新只从更新源下载带哈希校验的官方文件
- 磁盘分析只读展示，绝不自动删除文件
- 所有系统修改（启动项禁用 / 优化项）均可在应用内一键恢复
