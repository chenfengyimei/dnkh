系统要求
--------
- Windows 10（1709 及以上）或 Windows 11，64 位
- 无需安装 .NET 运行时
- 「电脑开荒网」内嵌页依赖系统 WebView2 运行时（Win10/11 一般随 Edge 自带）
- 「APP 推荐」一键安装依赖系统自带的 winget（App Installer）

安装与运行
----------
1. 将 Dnkhw.exe 放到任意目录（建议放在非系统盘，如 D:\Tools）
2. 双击运行
3. 首次运行如弹出 SmartScreen 蓝色提示：点「更多信息」→「仍要运行」
   （个人作品未购买代码签名证书的正常现象，软件本身是干净的）
4. 更省事的做法：右键文件 → 属性 → 勾选「解除锁定」→ 确定

权限说明
--------

- 在线更新不需要管理员权限（下载目录与 exe 重命名均无需提权）
