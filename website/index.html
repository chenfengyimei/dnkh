常见问题

没找到答案？可到反馈页提交问题或申请收录软件。

为什么首次运行会弹出蓝色 SmartScreen 提示？

个人作品未购买代码签名证书，Windows 对未签名程序会显示此提示，属正常现象。 点「更多信息」→「仍要运行」即可；更省事的做法是右键文件 → 属性 → 勾选「解除锁定」。 软件本身是干净的，建议下载后按上方方法核对 SHA256 确认完整性。

需要管理员权限吗？

默认以普通权限运行，开荒检查、壁纸、默认路径换盘、APP 推荐、磁盘分析均可正常使用。 仅系统级启动项、关闭遥测等少数操作需要提权——页面内会提示并提供「以管理员身份重启」按钮， 不需要提权的功能绝不要求。

它会修改我的系统吗？能恢复吗？

所有修改都通过官方公开机制完成（注册表、StartupApproved、powercfg、winget），并在应用内提供一键恢复。 启动项禁用采用与任务管理器相同的机制，不删除原始条目； 磁盘分析全程只读，绝不自动删除任何文件。

APP 推荐为什么只有 32 款软件？

收录标准只有一条：官方渠道、无捆绑安装器、无弹窗广告——宁缺毋滥。 软件清单（apps.json）随源码开源，符合标准的软件欢迎通过 官网反馈页提交收录申请。

软件会收集我的数据吗？

不会。仅有的联网行为是访问 Bing 壁纸接口、winget 官方源与官网内嵌浏览（「电脑开荒网」模块）； 「检查更新」只在你点击时联网访问官网一次，无任何后台静默检查。 除此之外没有任何遥测、统计或上报，也不需要注册账号。

「电脑开荒网」页面打不开或显示异常？

内嵌官网依赖系统的 WebView2 运行时，Win10 / 11 一般随 Edge 自带。 极少数精简系统缺失时，应用会给出安装指引，也可直接改用任意浏览器访问 app.cyhaoka.vip，功能完全一致。

支持哪些系统？为什么是约 67 MB 的单文件？

支持 Windows 10（1709 及以上）与 Windows 11 的 64 位系统。 为了实现「新机双击即用」，程序自带完整 .NET 运行时（自包含单文件），因此比普通软件大—— 换来的是免安装、免依赖，放到 U 盘里也能直接运行。
